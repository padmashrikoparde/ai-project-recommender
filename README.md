# AI-Based "What Should I Build?" System for Engineering Students

## Overview
An AI-powered project recommendation system that helps engineering students discover project ideas based on their academic branch, technical skills, interests, budget, difficulty preference, and career goals.

## Features
- Personalized project recommendations
- TF-IDF and cosine similarity-based matching
- Preference-based ranking adjustments
- Project difficulty and estimated duration
- Technology stack recommendations
- Step-by-step implementation roadmaps
- Interactive Streamlit dashboard

## Technologies
Python, Pandas, Scikit-learn, Streamlit

## Installation
1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Run `streamlit run app.py`.

## Future Enhancements
- Expand the project catalog.
- Add user accounts and saved projects.
- Integrate a generative AI API.
- Add project resource links and progress tracking.

## Limitations
The current prototype uses a small sample catalog. Recommendation scores are relative ranking indicators and do not guarantee project success or employability.# ai-project-recommender
